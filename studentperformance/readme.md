# Student Performance Analysis
Its a beginner-level Data Analysis project using Python, Pandas, and Matplotlib.

## features
- Reads student data from a CSV file.
- Calculates average marks for each student.
- shows the class topper and lowest scorer.
- Calculates class average.
- Finds highest and lowest marks.
- Visualizes student performance using a bar graph.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project Files
- `main.py` – Main Python program.
- `stu.csv` – Student dataset.

## How to Run
1. Install dependencies:
   `pip install pandas matplotlib`
2. Run:
   `python main.py`
